# 系统架构设计师备考知识库

> 全国计算机技术与软件专业技术资格（水平）考试 — 高级资格 · 系统架构设计师

将 721 页官方教材 + 考试大纲从扫描 PDF 中 OCR 提取，结构化为 Markdown 知识库，支持 **INDEX 索引 + 按需加载**，方便用 AI 辅助复习和检索。

---

## 知识库内容

### 00. 考试大纲（2022 年审定通过）

完整提取考试说明 + 三个科目考点：

- **科目一：综合知识** — 13 个知识领域、150 分钟选择题
- **科目二：案例分析** — 9 大架构设计实践、90 分钟问答题
- **科目三：论文** — 5 大选题方向、120 分钟论文题

### 01. 系统架构设计师教程（第4版）

官方教程全文提取，共 20 章，涵盖架构师考试全部基础知识与实践领域：

| 篇章 | 覆盖范围 |
|:---:|---|
| **上篇：基础知识** | 计算机系统、信息系统、信息安全、软件工程、数据库设计、架构设计基础、质量属性与评估、可靠性、架构演化、未来信息技术 |
| **下篇：实践专题** | 信息系统架构、层次式架构、云原生架构、SOA、嵌入式系统架构、通信系统架构、安全架构、大数据架构、论文写作 |

## 为什么做这个

1. **教材是扫描版 PDF**，无法搜索、无法复制、无法被 AI 读取
2. **721 页的内容**，翻书找知识点效率极低
3. 提取为 Markdown 后，可以直接丢给 Claude / ChatGPT 进行**定向问答、知识串联、模拟出题**
4. INDEX 按需加载设计，适配 AI 上下文窗口，不用一次塞入全部内容

---

## 使用建议

**配合 AI 工具使用效果最佳：**

- 先让 AI 读 `INDEX.md` 了解全局知识结构
- 针对薄弱章节，让 AI 读取对应文件进行讲解
- 让 AI 基于《考试大纲》的考点清单 + 《教材》内容生成模拟题
- 用《论文写作要点》章节练习论文框架
