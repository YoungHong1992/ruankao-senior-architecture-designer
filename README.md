# 系统架构设计师备考知识库

> 全国计算机技术与软件专业技术资格（水平）考试 · 高级资格 · 系统架构设计师

本仓库把考试大纲、教材 OCR 提取稿和历年试题整理为可检索的 Markdown，采用 **INDEX 索引 + 按需加载** 的方式，便于个人复习及 AI 辅助检索。

本项目是非官方学习资料库，与考试主管机构、原作者及出版社不存在隶属或授权关系。仓库内容可能含 OCR 错误、回忆版差异和缺失图表，不能替代依法取得的原书、考试主管机构发布的信息或其他权威资料。

## 使用方式

1. **查大纲或教材**：优先进入清洗版并先读 `INDEX.md`；遇到语义可疑、公式、表格或图示时，对照原始提取稿和依法取得的原资料。
2. **做历年真题**：必须先读 [02.历年真题总索引.md](02.历年真题总索引.md)，再打开其中标注的“首选文件”；不要在两个同名来源中随机选择。自动化工具可读取 [`data/exams.json`](data/exams.json)。
3. **使用 AI**：先提供索引，再提供与问题直接相关的章节；要求 AI 区分原文、整理者注释和推断，并核验答案来源。
4. **引用或作出重要判断**：回到考试主管机构、出版社或其他权威来源复核。本仓库不提供正确性、完整性或时效性保证。

适合的使用场景包括按考点检索、章节讲解、知识串联、错题整理和论文框架练习；不适合把仓库内容直接视为官方答案或逐字可靠的教材电子版。

## 图表与 OCR 限制

- 当前仓库没有随 Markdown 提交教材扫描图片或独立图表资产。
- PDF 中 284 个唯一教材图号与 59 个唯一表号均已建立独立 Markdown 载体；原 296 项资产债口径经逐页审计补发现 12 幅图，修正下限为 308 项并全部纳入账本。结构化重绘不是原始版式复制。
- 试题图表仅在来源足以支持时转录或重绘；无法唯一判定的题面、选项、空号、连线或答案继续显式标为“未恢复”“不可裁决”或“待复核”，不作猜测。
- 清洗稿仍可能含错字、断句、拼栏、标题层级错误或未经确认的答案。
- 教材源 PDF 未纳入版本库；仓库保存其本地路径描述、页码和 SHA-256 以便持有该文件的用户复核，但仅凭版本库仍不能完整复现 OCR 提取过程。

图题保留、缺图标记、可重建示意图和未来图表资产的处理规则见 [FIGURE_POLICY.md](FIGURE_POLICY.md)。

## 质量检查

本地运行 `python scripts/validate_knowledge_base.py` 可检查索引、链接、题号、UTF-8、标题层级、高风险 OCR 词、真题 manifest、117 点位账本、教材页级审计结果及两份索引日期一致性。持有源 PDF 时可运行 `python scripts/audit_textbook_pdf.py <PDF路径>` 重建教材审计数据。`.github/workflows/knowledge-base-quality.yml` 执行不依赖源 PDF 的同一质量门禁；检查通过不等同于内容已获考试主管机构或出版社认证。
