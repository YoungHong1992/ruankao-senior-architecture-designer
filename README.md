> 全国计算机技术与软件专业技术资格（水平）考试 · 高级资格 · 系统架构设计师

## 使用方式

1. **查大纲或教材**：优先进入清洗版并先读 `INDEX.md`；遇到语义可疑、公式、表格或图示时，对照原始提取稿和依法取得的原资料。
2. **做历年真题**：必须先读 [02.历年真题总索引.md](02.历年真题总索引.md)，再打开其中标注的“首选文件”；不要在两个同名来源中随机选择。自动化工具可读取 [`data/exams.json`](data/exams.json)。
3. **使用 AI**：先提供索引，再提供与问题直接相关的章节；要求 AI 区分原文、整理者注释和推断，并核验答案来源。
4. **引用或作出重要判断**：回到考试主管机构、出版社或其他权威来源复核。本仓库不提供正确性、完整性或时效性保证。

适合的使用场景包括按考点检索、章节讲解、知识串联、错题整理和论文框架练习；不适合把仓库内容直接视为官方答案或逐字可靠的教材电子版。

## 图表与 OCR 限制

- 当前仓库没有随 Markdown 提交教材图片或独立图表资产。
- 正文保留了部分图题及“如图 X-X 所示”等引用，但图中结构、公式、连线和标签可能完全缺失。
- 部分试题依赖原图或原表；缺失处应显式标为“原图/原表缺失”或“待复核”，不得凭空补画或臆测题意。
- 清洗稿仍可能含错字、断句、拼栏、标题层级错误或未经确认的答案。
- 源 PDF 未纳入版本库，因此仅凭本仓库不能完整复现 OCR 提取过程。

图题保留、缺图标记、可重建示意图和未来图表资产的处理规则见 [FIGURE_POLICY.md](FIGURE_POLICY.md)。

## 质量检查

本地运行 `python scripts/validate_knowledge_base.py` 可检查索引、链接、题号、UTF-8、标题层级和高风险 OCR 词。`.github/workflows/knowledge-base-quality.yml` 在 GitHub Actions 中执行同一质量门禁，检查名称为 `knowledge-base-quality`。检查通过只能证明已配置的结构与规则满足要求，不等同于内容已获官方校对。
