# 教材核查与图表复原作业规程（首轮经验固化）

2026-09-26 由第 1、2 章首轮实践固化，供后续章节与轮次直接复用。本规程是 AGENTS.md 的作业细则；与 AGENTS.md 冲突时以 AGENTS.md 为准。

## 0. 开工前

- 分支与 PR：每章（或相邻两章）一个 PR，不直接推送 main；`tmp/` 为 gitignored 工作区，页面渲染与放大产物只放 `tmp/`，不入库。
- 页码映射抽查：本教材「印刷页 = 物理页 − 9」，每章开工先抽 2–3 处页眉读数确认偏移，再批量渲染。
- 工具命令（解释器一律 `uv run`，不要裸调 python——Windows 下裸 python 是存根，heredoc 会静默失败）：
  - 整页渲染（pypdfium2 + pillow，1400px 灰度 JPEG，全章一次渲染备用）：

    ```bash
    uv run --with pypdfium2 --with pillow python - <<'PY'
    import pypdfium2 as pdfium
    pdf = pdfium.PdfDocument('sources/01-系统架构设计师教材/系统架构设计师教程(第2版).pdf')
    for i in range(32, 113):  # 物理页从 1 计数；区间按章调整
        page = pdf[i-1]
        img = page.render(scale=1400/595).to_pil().convert('L')
        img.save(f'tmp/tb-r1/{i:03d}.jpg', quality=80)
    PY
    ```

  - 局部放大取证（小字必须放大到逐字确认，常用 3–14×）：

    ```bash
    uv run --with pillow python -c "
    from PIL import Image
    im = Image.open('tmp/tb-r1/063.jpg'); w,h = im.size
    c = im.crop((int(w*0.30), int(h*0.02), int(w*1.0), int(h*0.32)))
    c = c.resize((int(c.width*2.6), int(c.height*2.6)), Image.LANCZOS)
    c.save('tmp/xxx.png')"
    ```

  - SVG 渲染自检（resvg_py 只暴露 `svg_to_bytes`，没有 `svg_to_png`）：

    ```bash
    uv run --with resvg-py python -c "
    from resvg_py import svg_to_bytes
    import pathlib
    svg = pathlib.Path('<asset>.svg').read_text(encoding='utf-8')
    pathlib.Path('tmp/xx.png').write_bytes(bytes(svg_to_bytes(svg_string=svg, width=1300)))"
    ```

  - 并排对比：PIL 把原书裁剪与渲染图等高拼接成一张图，人工终检用。

## 1. 文字核查轮次

- 组织：按节分轮，每轮一个干净上下文子代理（不携带任何既有结论）；一轮覆盖一节的正文 + 对应扫描页。整章文字核查约 10–15 轮。
- 铁律：**图先于稿**（先读扫描件再读清洗稿）；一次只裁一个图/段；字符级主张必须 3–14× 放大取证后才可写进结论；原书怪字照录；证据不足写「无法判定」，不得猜测；不得使用 OCR 与 PDF 文本层。
- 冲突裁决：两次干净阅读结果冲突、或子代理主张与稿面不符时，验证者亲自回图放大裁决。子代理会误读（已记录在案：图 1-7 软件度量年份、DevOps 年份），旧草稿日志与入库扫描件冲突时以入库件为准。
- 落地：正文只写勘误后的正确内容（正文纯净，不携带任何注记）；原书错误与存疑进 `catalog/errata.json`（`anchor` 必须在所指正文恰好出现一次；`kind: typo|noted`）；过程、裁决、怪字清单写本章核查记录 `verification/教材首轮核查-第NN章-标题.md`。
- 成本参考：普通节每轮数十万 token；一章文字盲核合计约 2000 万+ token。

## 2. 图表 SVG 复原

- 登记先行：逐项登记 `catalog/figures.json`——`anchor` 用完整图题行（含 `> ` 前缀，保证正文唯一）；`asset` 为 SVG 相对路径；`note` 记结构与怪字。
- 口径：一律手工 SVG；**表也用 SVG**；原图没有的元素（箭头、连线、框）不画；看不清的连线以虚线呈现并在 note 声明；原书怪字照录；正文以 Markdown 图片语法引用 SVG（链接目标为 asset 相对路径），图下随图题行；`<desc>` 写复原出处与结构要点（注意转义裸 `<<`，否则 resvg 报 invalid name token）。
- 布局方法：简单图手写坐标；密集大图（泳道图、矩阵表、用例图）先派「测量代理」实测全部标签的页面分数坐标，再以生成器脚本编译 SVG（图 1-7、图 2-16 路线，单图 600 万+ token）。
- 自检：resvg 渲染 PNG 后逐幅目检四类硬伤——文字溢出/叠印、连线穿字、箭头方向、漏元素。
- 干净子代理盲比（AGENTS.md 强制）：每批 5–11 幅；输入只有渲染 PNG + 扫描页路径，**不给任何修复上下文**；要求比对①元素清单（逐字）②拓扑（连线方向/分叉/容器嵌套/合并格）③旁注引线指向④布局方位，并附放大证据文件。
- 收敛：修复 → 重渲染 → 复验循环；复验常不止一轮（第 2 章三轮才收敛：11 → 5 → 1 → 0），每轮只送上轮 FAIL 项。**干净代理也会漏检**——维护者并排终检不可省（图 2-15 的回环弧即三轮盲比通过后由人工比对发现）。
- 成本参考：普通小图每幅数万 token；复杂大图单幅数百万；全量盲比六批约 1500 万 + 复验约 1200 万 token。

## 3. 已知陷阱（逐条踩过）

- 换行：全部 `.md` 必须 CRLF（Write 新文件后 `sed -i 's/$/\r/'` 转换）；`.json/.py` 用 LF。全部文本 UTF-8 无 BOM。
- 锚点唯一：正文中图题字符串出现两次（如图片 alt 含图题）会让 figures.json 校验失败——anchor 用完整图题行、alt 用文件名式描述。
- 生成器脚本重跑会覆盖手工修过的 SVG（表 2-7 曾被覆盖回坏版）：手工定稿后弃用生成器或改输出路径。
- 资产文件名序号两位零填充（`figure-02-05.svg`），目录名不含小数点。
- 新增/删除正文文件必须同步 `catalog/corpora.json` 的 `expected_documents`；每个目录的 `INDEX.md` ≤200 行且收录全部子项。
- 提交前本地跑齐 CI 四件套：`uv lock --check`、主校验、`ruff check`、`ruff format --check`。

## 4. 遗留与升级路径

- 两章全部存疑项在核查记录与 figures.json note 中带证据文件名/页码，后续高清复核按编号定位即可，无需重查。
- 第二轮独立盲核：任务包模板见下节；第 1、2 章已试点，其余章节的推广节奏待试点结论确定。

## 5. 第二轮独立盲核（任务包模板）

第二轮的审计对象是**首轮的产出**（修订后正文 + 两本登记簿），回答三个问题：首轮修订是否站得住（含过度勘正检测）、登记簿描述性字段是否可靠、首轮未覆盖的维度（标题层级、段落切分）有无系统性偏差。

- 组织：逐节一轮，每轮一个干净上下文盲核子代理；验证者（知晓首轮记录）逐轮做首轮对照、覆盖检查并回图裁决分歧；分歧不以多数票裁定，只认图像。
- 隔离：盲核者可见 = 本节扫描页渲染 + 本节清洗稿 + 指向本节的 errata 条目；禁读 = 首轮核查记录、`catalog/figures.json`、待重画图表清单、AGENTS.md、本规程、git 历史与 PR 描述、任何首轮结论。
- 反确认偏置：errata 条目是唯一获准给出的"答案"，因此任务包必须同时要求——每条勘误亲自放大图面复核依据；若图面与 `corrected` 一致（原书未印错却被改），必须作为「过度勘正」报出。
- 范围：正文逐字、公式、标题层级（以字体加粗/缩进为证据）、段落切分（判据：原书段首缩进 2 字、续行顶格）、图题/表题/图号与正文引用。图内元素（节点、连线、拓扑）不在第二轮范围——首轮已经过盲比-修复-复验的对抗性收敛，与文字的单遍核查性质不同。
- 判据口径：标点全角/半角在扫描分辨率下不可判定，不得作为差异判据报出；发现原书自身混用处登记 `noted` 留待裁决，不直接勘正。
- 记录：逐轮「盲核记录原样收录 + 验证者裁决」汇入本章第二轮记录文件，语气对标大纲独立盲核记录（证据前置、结论克制）；全部轮次完成后由维护者对待裁决项逐项拍板，修正与记录分开提交。

任务包存 `tmp/`（脚手架，不入库），每轮只换「范围」一节，其余固定：

```markdown
# 盲核任务包 —— 第NN章 第NN节

## 范围
- 清洗稿：<节文件路径>
- 扫描页：tmp/tb-r2/NNN.jpg – NNN.jpg（物理页；印刷页 = 物理页 − 9，以页眉读数为准）
- 基线：<分支名> @ <HEAD 提交>

## 可见与禁读
只允许读：本任务包、上述扫描页图像、上述清洗稿文件；可用命令裁剪放大图像。
禁止读：verification/、catalog/、AGENTS.md、git 历史、PR、首轮记录、其他章节文件。

## errata 条目（须逐条放大回图复核依据；发现过度勘正必须报出）
<本节条目：id、anchor、original→corrected、物理页/印刷页、note>

## 输出（写入 tmp/tb-r2/blind-<id>.md，覆盖全部页面不跳页）
| 清洗稿定位 | PDF 物理页/图像区域 | 结果 | 观察或差异 | 证据文件 |

结果 ∈ 相符 / 有差异 / 无法判定。字符级主张必须 2.6×–40× 放大取证后才可写入；
无法判定如实写，不得猜测；不评价原书内容对错；不把标点宽度报为差异。

## 放大命令
uv run --with pillow python -c "…同规程 §0 局部放大取证…"
```
