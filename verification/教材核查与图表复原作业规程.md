2026-09-26 由第 1、2 章首轮实践固化，供后续章节与轮次直接复用；2026-10-08 按第 3、4 章第二轮盲核经验增补：字符级判读与层级像素测量标准（§0/§1）、占位记号必答、errata 引用与收尾两查、模型拒答降级预案（§3）、无视觉验证者的裁决代理规范（§5）；2026-10-09 根据第 3、4 章 SVG 后补核查暴露的流程缺口，将图表盘点、SVG 复原与独立盲比明确并入同节首轮（§1/§2），并限定第二轮对图内元素的排除条件（§5）。本规程是 AGENTS.md 的作业细则；与 AGENTS.md 冲突时以 AGENTS.md 为准。

## 0. 开工前

- 分支与 PR：每章（或相邻两章）一个 PR，不直接推送 main；`tmp/` 为 gitignored 工作区，页面渲染与放大产物只放 `tmp/`，不入库。
- 页码映射抽查：本教材「印刷页 = 物理页 − 9」，每章开工先抽 2–3 处页眉读数确认偏移，再批量渲染。
- 工具命令（解释器一律 `uv run`，不要裸调 python——Windows 下裸 python 是存根，heredoc 会静默失败）：
  - 整页渲染（pypdfium2 + pillow，1400px 灰度 JPEG，全章一次渲染备用）：

    ```bash
    uv run --with pypdfium2 --with pillow python - <<'PY'
    import pypdfium2 as pdfium
    pdf = pdfium.PdfDocument('sources/01-系统架构设计师教材/系统架构设计师教程(第2版).pdf')
    for i in range(32, 113):  # 物理页从 1 计数；区间按章调整
        page = pdf[i-1]
        img = page.render(scale=1400/595).to_pil().convert('L')
        img.save(f'tmp/tb-r1/{i:03d}.jpg', quality=80)
    PY
    ```

  - 局部放大取证（小字必须放大到逐字确认，常用 3–14×）：

    ```bash
    uv run --with pillow python -c "
    from PIL import Image
    im = Image.open('tmp/tb-r1/063.jpg'); w,h = im.size
    c = im.crop((int(w*0.30), int(h*0.02), int(w*1.0), int(h*0.32)))
    c = c.resize((int(c.width*2.6), int(c.height*2.6)), Image.LANCZOS)
    c.save('tmp/xxx.png')"
    ```

  - 字符终读（字形归属存疑或低倍读不出时，先做最近邻高倍复测，复测仍不辨才可记「无法判定」；NEAREST 不平滑、保留像素骨架，LANCZOS 会把字骨抹圆）：

    ```bash
    uv run --with pillow python -c "
    from PIL import Image
    im = Image.open('tmp/tb-r2/scan/NNN.jpg'); c = im.crop((x1,y1,x2,y2))
    c = c.resize((c.width*20, c.height*20), Image.NEAREST)
    c.save('tmp/xxx-20x-nearest.png')"
    ```

  - SVG 渲染自检（resvg_py 只暴露 `svg_to_bytes`，没有 `svg_to_png`）：

    ```bash
    uv run --with resvg-py python -c "
    from resvg_py import svg_to_bytes
    import pathlib
    svg = pathlib.Path('<asset>.svg').read_text(encoding='utf-8')
    pathlib.Path('tmp/xx.png').write_bytes(bytes(svg_to_bytes(svg_string=svg, width=1300)))"
    ```

  - 并排对比：PIL 把原书裁剪与渲染图等高拼接成一张图，人工终检用。

## 1. 首轮逐节事实核查（正文与图表一体）

- 组织：按节分轮，每轮一个干净上下文子代理（不携带任何既有结论）；同一轮覆盖一节的正文 + 对应扫描页，并同时盘点这些页面中的原书图和表。整章文字核查约 10–15 轮。SVG 绘制和盲比可由不同的隔离任务承担，但须使用同一节、同一轮的范围，并在该节首轮记录中共同收口；不得先把文字首轮标为完成、再另开一轮补图。
- 完成门槛：逐页核文字时记录本节扫描页内实际出现的图表、图题/表题和正文引用；已有 SVG 必须逐项回到扫描页核对，缺失且需保留的 SVG 按 §2 复原。该节所有图表均须有明确处置；需要保留的 SVG 还须完成渲染、干净上下文盲比及必要的修订复验，并核对正文引用与 `catalog/figures.json` 后，才可标记首轮完成。纯装饰且正文未引用的图形按 AGENTS.md 规则删除；若原图整体无法可靠辨认，按治理规则只保留图题并在记录中说明具体限制；局部不可辨认细节按 §2 留空并记录，不得猜补。核查记录至少列物理页、图/表号与题注、正文定位、处置（已有 SVG 回图/本轮复原/装饰删除/受限仅留题注）、资产路径（如有）、盲比与复验结果、未决项，作为交接证据，不形成全库覆盖率或数量目标。
- 铁律：**图先于稿**（先读扫描件再读清洗稿）；一次只裁一个图/段；版面/段落级主张 2.6×–8× 带状取证即可；**字符级主张（字形归属、单字差异）必须 20×–40× 放大并附同页已知字形对照**（如以同页问号/数字/小写 l 样本并排比对后下结论），低倍读不出时先做 NEAREST 高倍复测（§0 命令），复测仍不辨才可写「无法判定」（第 3、4 章实测：「?/7」「l/│/\」「有无下标」三类初判均被高倍对照推翻或定案）；原书怪字照录；不得猜测；不得使用 OCR 与 PDF 文本层。
- 首轮必查维度（2026-09-29 自第二轮试点反哺，此前首轮只查正文逐字，层级/段落偏差要靠第二轮兜底）：**标题层级**与**段落切分**与正文逐字同为必查。判据——段落以「原书段首缩进 2 字、续行顶格」为准：顶格续行不得切为新段，原书缩进的独立段不得并入上段或列表项；标题以字重/字号/缩进为证据，**涉层级或字重的判定必须附像素测量**——笔画粗细代理 medrun（本扫描下正文恒 2.0、加粗恒 3–4，两群不重叠）辅以墨迹密度与行首缩进 x 值，不以视觉印象单独定案（第 3、4 章实测：同一「N)」式版面三轮盲核分别判差异/相符/建议降级，最终由测量定案）。「N)」式行按字号证据分两类处置：**小一号**次级小目（第 1、2 章式）降一级、编号统一写「#### N.」（2026-09-29 维护者定稿，全书一致，不恢复印面「N)」）；**与正文同字号且不加粗**的正文级编号行（medrun 2.0、行首=段首缩进、半角「N)」紧排）不升标题，照录为普通行（2026-10-08 第 3、4 章定稿，DSS/TPS/ERP 及 4.5/4.6 共 21 处）。
- 标点与不可判定口径（同日定稿）：标点全角/半角宽度不作判据；**标点种类归一（原书该用顿号处印逗号一类）属该修的排印错误**，勘正并登记 errata；被笔画压盖、最大倍率仍读不出的字按「无法判定」处理，不计差异；正文不加任何编者标记（如主码加粗），原书自身前后不一处照录印面 + errata(noted)。**占位/残缺记号（上标或下标位为空白、问号、环形墨迹、屋顶形脱字符等）一律照录原书形态，不得以数学正确性或外部知识补写具体值**（2026-10-08 第 3、4 章裁定，同 tb-0020 先例：$2^{56}$、$8^7$、$C^7$、N₁/N₂、={R,W}、$2^N$ 六处补写全部回滚并登记 noted）；任务包把「本节有无此类占位记号」列为必答项。
- 冲突裁决：两次干净阅读结果冲突、或子代理主张与稿面不符时，验证者亲自回图放大裁决。子代理会误读（已记录在案：图 1-7 软件度量年份、DevOps 年份），旧草稿日志与入库扫描件冲突时以入库件为准。
- 落地：正文只写勘误后的正确内容（正文纯净，不携带任何注记）；原书错误与存疑进 `catalog/errata.json`（`anchor` 必须在所指正文恰好出现一次；`kind: typo|noted`）；过程、裁决、怪字清单写本章核查记录 `verification/教材首轮核查-第NN章-标题.md`。
- 成本参考：普通节每轮数十万 token；一章文字盲核合计约 2000 万+ token。轮间差异可达 20 倍以上（第 3、4 章实测单轮 17 万–450 万）：公式/字符密集节按上限预算、纯散文节按下限；字形对照与 NEAREST 终读等追加测量单次数万至数十万。

## 2. 图表 SVG 转录、核查与盲比（并入首轮）

- 范围与时序：本节工作与 §1 共用同一节、同一批扫描页。开始文字核查时即盘点页面中的图表；已有 SVG 不能因已存在或已登记而视为通过，缺失 SVG 也不能留到文字首轮结束后再补。按 §1 完成门槛收口。
- 登记先行：逐项登记 `catalog/figures.json`——`anchor` 用完整图题行（含 `> ` 前缀，保证正文唯一）；`asset` 为 SVG 相对路径；`note` 记结构与怪字。
- 口径：一律手工 SVG；**表也用 SVG**；原图没有的元素（箭头、连线、框）不画；看不清的连线以虚线呈现并在 note 声明；原书怪字照录；正文以 Markdown 图片语法引用 SVG（链接目标为 asset 相对路径），图下随图题行；`<desc>` 写复原出处与结构要点（注意转义裸 `<<`，否则 resvg 报 invalid name token）。
- 布局方法：简单图手写坐标；密集大图（泳道图、矩阵表、用例图）先派「测量代理」实测全部标签的页面分数坐标，再以生成器脚本编译 SVG（图 1-7、图 2-16 路线，单图 600 万+ token）。
- 自检：resvg 渲染 PNG 后逐幅目检四类硬伤——文字溢出/叠印、连线穿字、箭头方向、漏元素。
- 干净子代理盲比（AGENTS.md 强制）：每批 5–11 幅；输入只有渲染 PNG + 扫描页路径，**不给任何修复上下文**；要求比对①元素清单（逐字）②拓扑（连线方向/分叉/容器嵌套/合并格）③旁注引线指向④布局方位，并附放大证据文件。
- 收敛：修复 → 重渲染 → 复验循环；复验常不止一轮（第 2 章三轮才收敛：11 → 5 → 1 → 0），每轮只送上轮 FAIL 项。**干净代理也会漏检**——维护者并排终检不可省（图 2-15 的回环弧即三轮盲比通过后由人工比对发现）。
- 成本参考：普通小图每幅数万 token；复杂大图单幅数百万；全量盲比六批约 1500 万 + 复验约 1200 万 token。

## 3. 已知陷阱（逐条踩过）

- 换行：全部 `.md` 必须 CRLF（Write 新文件后 `sed -i 's/$/\r/'` 转换）；`.json/.py` 用 LF。全部文本 UTF-8 无 BOM。
- 锚点唯一：正文中图题字符串出现两次（如图片 alt 含图题）会让 figures.json 校验失败——anchor 用完整图题行、alt 用文件名式描述。
- 生成器脚本重跑会覆盖手工修过的 SVG（表 2-7 曾被覆盖回坏版）：手工定稿后弃用生成器或改输出路径。
- 资产文件名序号两位零填充（`figure-02-05.svg`），目录名不含小数点。
- 新增/删除正文文件必须同步 `catalog/corpora.json` 的 `expected_documents`；每个目录的 `INDEX.md` ≤200 行且收录全部子项。
- 提交前本地跑齐 CI 四件套：`uv lock --check`、主校验、`ruff check`、`ruff format --check`。
- errata→record 溯源断言只认**完整 id 字符串**：记录文件不得写「tb-0031/32」「tb-0042～0046」等紧凑引用，须逐一展开（第 1、2 章与第 3、4 章已各踩一次）。
- 模型内容过滤器可能拒绝含特定词汇的页面图像（2026-10-08 实测：glm-5.3-flash 对含「密码机」的物理页 158–159 三次 400 拒答，触发点在图像内容、换措辞无效）：先重试一次，仍拒则改由相邻轮的边界记录交叉佐证并在核查记录如实登记；整段被拒的页标记转人工或其他通道，不得以无取证状态蒙混过关。
- 落地收尾两查：①计划修订清单逐条 grep 核对已实际落盘（第 3、4 章曾 6 处公式修订未入脚本仍被误报完成）；②每次提交后 `git show --stat` 复核文件数、`git status` 查漏（git add 混入一个无效 pathspec 会中止整条暂存，stderr 被吞时无感）。

- 第二轮独立盲核：任务包模板见下节；第 1、2 章试点已完成并裁决收口（2026-09-29，记录见 `教材第二轮独立盲核记录-第01-02章.md` §八），后续章节随首轮完成后逐章推进；同父重号门禁按 `catalog/corpora.json` 教材语料的 `blind_checked_chapters` 名单生效，随章节完成扩列。

## 5. 第二轮独立盲核（任务包模板）

第二轮的审计对象是**首轮的产出**（修订后正文 + 两本登记簿），回答三个问题：首轮修订是否站得住（含过度勘正检测）、登记簿描述性字段是否可靠、首轮未覆盖的维度（标题层级、段落切分）有无系统性偏差。

- 组织：逐节一轮，每轮一个干净上下文盲核子代理；验证者（知晓首轮记录）逐轮做首轮对照、覆盖检查并回图裁决分歧；分歧不以多数票裁定，只认图像。验证者自身无图像理解能力时，回图裁决经**独立多模态复核代理**执行（与盲核代理不同实例、不共享结论）；**凡推翻登记簿既有认定的判定，须追加一道「不知争议内容」的盲态复验**后方可执行（tb-0027「^」过度勘正即由两个盲态代理独立描述同一字形后定案）。
- 隔离：盲核者可见 = 本节扫描页渲染 + 本节清洗稿 + 指向本节的 errata 条目；禁读 = 首轮核查记录、`catalog/figures.json`、待重画图表清单、AGENTS.md、本规程、git 历史与 PR 描述、任何首轮结论。
- 反确认偏置：errata 条目是唯一获准给出的"答案"，因此任务包必须同时要求——每条勘误亲自放大图面复核依据；若图面与 `corrected` 一致（原书未印错却被改），必须作为「过度勘正」报出。
- 范围：正文逐字、公式、标题层级（以字体加粗/缩进为证据）、段落切分（判据：原书段首缩进 2 字、续行顶格）、图题/表题/图号与正文引用。图内元素（节点、连线、拓扑）不在第二轮范围，**前提是该节已按 §1/§2 在首轮完成 SVG 对照、盲比、修复与复验**，其对抗性收敛流程不同于文字的单遍核查。首轮未完成的图表不能借此排除条款免核；须补做并在记录中明确标为后续补核，不得倒记为首轮已完成。
- 判据口径：标点全角/半角不作判据；标题层级/字重判定附像素测量、字符级主张按 §1 铁律取证（20×–40× + 同页字形对照）；发现原书自身混用处登记 `noted` 留待裁决，不直接勘正。
- 记录：逐轮「盲核记录原样收录 + 验证者裁决」汇入本章第二轮记录文件，语气对标大纲独立盲核记录（证据前置、结论克制）；全部轮次完成后由维护者对待裁决项逐项拍板，修正与记录分开提交。

任务包存 `tmp/`（脚手架，不入库），每轮只换「范围」一节，其余固定：

```markdown
# 盲核任务包 —— 第NN章 第NN节

## 范围
- 清洗稿：<节文件路径>
- 扫描页：tmp/tb-r2/NNN.jpg – NNN.jpg（物理页；印刷页 = 物理页 − 9，以页眉读数为准）
- 基线：<分支名> @ <HEAD 提交>

## 可见与禁读
只允许读：本任务包、上述扫描页图像、上述清洗稿文件；可用命令裁剪放大图像。
禁止读：verification/、catalog/、AGENTS.md、git 历史、PR、首轮记录、其他章节文件。

## errata 条目（须逐条放大回图复核依据；发现过度勘正必须报出）
<本节条目：id、anchor、original→corrected、物理页/印刷页、note>

## 输出（写入 tmp/tb-r2/blind-<id>.md，覆盖全部页面不跳页）
| 清洗稿定位 | PDF 物理页/图像区域 | 结果 | 观察或差异 | 证据文件 |

结果 ∈ 相符 / 有差异 / 无法判定。版面/段落级主张 2.6×–8× 取证；字符级主张必须 20×–40× 放大并附同页已知字形对照，低倍读不出先做 NEAREST 复测；
无法判定如实写，不得猜测；不评价原书内容对错；不把标点宽度报为差异。

## 放大命令
uv run --with pillow python -c "…同规程 §0 局部放大取证…"
```
