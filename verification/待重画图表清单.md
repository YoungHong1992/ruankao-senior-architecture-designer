# 待重画图表清单

这些位置此前曾放置由 AI 生成的 Mermaid 示意图。经比对原始 OCR 文本，其节点文字总命中率约 53%；

即使节点文字全部命中的图，连线方向与拓扑在原文中也没有依据（例如教材图 2-3，9 个节点全部有出处，

14 条连线全部为生成内容）。原始图像不在仓库内，等价性无法核实，因此已全部移除，正文只保留图题与文字说明。



## 恢复条件



为其中某一项补画图形，必须同时满足：



1. 补画者手中有该图的原始图像（依法取得的原书或原卷），并在补画时实际对照；

2. 节点数量、节点文字、连线方向、层次归属与原图逐一一致；

3. 不补画原图没有的元素；原图看不清的部分留空，并在图题或 `<desc>` 中写明未恢复的部分；

4. 形式按原图性质选择：行列对应表用 Markdown 表格；流程、时序、状态、树形用 Mermaid；

   几何关系本身承载信息（跨边界、嵌套包含、带编号部件的物理布局）的用独立 `.svg` 文件引用，不内联。



补画完成后删除本清单中对应条目。**没有原图就不要补画**——保留图题与正文说明是合格状态，不是缺陷。
