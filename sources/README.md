# sources —— 来源层

本目录存放**第三方原始材料**：教材与大纲的源 PDF，以及真题的本地原始/补充整理稿。
它与 [`content/`](../content/INDEX.md) 的职责边界是硬性的：

| 层 | 放什么 | 谁来改 | 是否上网页 / 进 RAG |
|---|---|---|---|
| `sources/` | 第三方原件与原始整理稿 | 只在纳入新来源时增删，不做文字加工 | 否 |
| `content/` | 本仓库清洗、校对后的正文 | 按清洗标准持续修订 | 是 |

## 规则

1. **源扫描件仅限两份已登记文件入库。** `catalog/corpora.json` 标 `committed: true` 的两份 PDF
   随仓库入库（`.gitignore` 用 `!` 反选放行，校验器双向核对 git 跟踪集合与登记清单）；
   其余 `*.pdf` 与 `sources/**` 下的图片格式一律不入库。书目信息、页数与 SHA-256 记在
   [catalog/corpora.json](../catalog/corpora.json)。
2. **来源层不做文字加工。** 发现 OCR 错误、断句问题时改 `content/` 下的清洗稿，不要回头改来源稿。
3. **同名冲突不合并。** `02-历年真题` 与 `02-历年真题(补充)` 中有 17 组同名但内容不同的文件，
   一律保留为独立版本，选用规则见 [历年真题总索引](../content/02-历年真题总索引.md)。
4. 新增来源时同步登记 [DATA_SOURCES.md](../DATA_SOURCES.md) 与 [catalog/](../catalog/README.md)。

权利边界见 [AGENTS.md 的「内容与权利政策」](../AGENTS.md#内容与权利政策)。
