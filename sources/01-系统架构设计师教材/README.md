## 已知事实与限制

- 共 **720 个 PDF 页**：整页扫描图像 + 可抽取的 **OCR 文本层**（719 页有文字，1 页为纯图）。
- 正文印刷页覆盖 **3—712**。印刷页 **403—404** 不在该 PDF 中：
  PDF 第 411 页是第 12 章首页（印刷页 405），其前一页为印刷页 402。
  全书分上下两篇（上篇第 1—11 章、下篇第 12—20 章），该缺口正落在两篇交界处，
  位置与「下篇分隔页 + 其背面空白页」吻合，**判断不涉及正文缺失**；原页不在手，
  这是结构推断而非核实结论，故仍如实登记。
- 各章起始印刷页由页眉推导，并与书内目录逐条核对一致；结果写入清洗稿 frontmatter 的
  `source_pages` 字段，见 [`content/01-系统架构设计师教材-清洗版/`](../../content/01-系统架构设计师教材-清洗版/INDEX.md)。

  是那份 721 页文件；因 `source_pages` 记的是**印刷页**而非 PDF 物理页，删页不影响页码映射。

## 使用方式

把源 PDF 放到本目录后即可用于人工比对与页码核对；`.gitignore` 会挡住 `*.pdf`，不会被误提交。
不要把 PDF、扫描页图或其下载链接提交到版本库，理由见 [AGENTS.md 的「内容与权利政策」](../../AGENTS.md#内容与权利政策)。
