# 计算机系统与网络及性能计算

本篇为 AI 辅助整理的非官方学习手册。概念采用教材归纳与明确标出的工程补充；口诀、例题、答案及作答模板均为教学归纳，不是官方答案或真实项目事实。优先级是学习安排，样本考频不代表未来命题概率。

## 学习范围与优先级

优先级 P1。2023 年起仓库五场考试的主主题统计：综合知识 47 题、案例 0 道大题、论文 0 题。每题只归一个主主题；组内粒度不同，计数不代表单考点概率或预测分值。具体题号与分年结果见[样本记录](../../verification/核心考点精要-考频样本.md)，覆盖边界见[覆盖表](11-大纲与教材考点覆盖表.md)。

## 五分钟速记

- 进程拥有资源，线程是执行与调度的重要单位；同进程线程共享部分资源，各自有栈和寄存器上下文。
- 时间片用完：运行→就绪；等待 I/O：运行→阻塞；I/O 完成：阻塞→就绪。
- 死锁四条件：互斥、请求并保持、不可剥夺、循环等待。
- 页内偏移位数由页大小决定；位图一位表示一个管理单元，最后换算为字节。
- 发送时延＝数据长度／链路速率；传播时延＝距离／传播速度。
- 系统加速受未优化部分限制；主频、带宽和资源利用率都不是完整性能结论。

## 1 CPU、存储与基本计算

CPU 执行时间＝指令条数×平均 CPI／时钟频率；频率相同不代表执行同一任务时间相同。RISC 与 CISC 是指令系统设计取向，不能只据名称判断实际处理器快慢。

Cache 利用时间与空间局部性。若未命中额外罚时为 P、命中时间为 H、未命中率为 m，则平均访问时间为 H+mP；若题目给的是未命中总时间，则加权方式不同，先辨别定义。

| 存储 | 记忆抓手 |
|---|---|
| SRAM | 无需周期刷新，常用于高速缓存 |
| DRAM | 需刷新，常用于主存 |
| ROM／PROM／EPROM／EEPROM | 从只读、一次编程到可擦除／电擦除的不同形式 |
| Flash | 非易失存储，擦写以一定组织单位进行 |

流水线的理想模型：k 段、每段时间 t、n 个任务，总时间为 (k+n−1)t；单任务延迟不因此自动变为 t。段长不等、停顿和相关都会改变结果。

RAID 0 条带化不提供冗余；RAID 1 镜像；RAID 5 分布式单校验可容忍一盘失效；RAID 6 双校验可容忍两盘失效，均需满足相应实现条件。RAID 不代替备份。

## 2 进程、同步与死锁

互斥保护一次仅一个执行者进入临界区；同步规定执行先后。信号量 P／wait 申请资源，V／signal 释放或通知；整数负值代表等待者数量是某种教材实现约定，不是所有系统 API 的定义。

生产者消费者经典顺序：生产者先等空槽，再拿互斥锁，写入后释放互斥并通知满槽；消费者先等满槽，再拿互斥，读出后释放并通知空槽。不能持有互斥锁再等待对方必须进入临界区才能产生的条件。

死锁预防破坏必要条件；避免依据未来最大需求判断是否进入安全状态；检测允许发生后发现并恢复。**不安全状态不等于已经死锁。**

银行家算法步骤：找 Need≤Work 的进程，假定它完成并释放 Allocation 到 Work，反复找；能完成全部进程则存在安全序列。

自编简式：n 个进程，每个最多需要 k 个同类可复用资源，在逐个申请等假设下，要保证不会出现全部各占 k−1 个而等待，可提供 n(k−1)+1 个资源。必须读题约束，不能推广到任意多类资源。

调度：先来先服务可能产生长任务阻塞；短作业优先有利于平均等待但可能饥饿；时间片轮转重交互公平，时间片过小增加切换成本；优先级调度需考虑低优先级饥饿。

## 3 存储与文件管理

分页是固定大小块，分段按逻辑实体划分且长度可变。页大小为 2^p 字节时，页内偏移为 p 位；地址翻译用页号查页表得到页框，再拼偏移。

自编例：4 KiB 页，偏移 12 位；16 GiB 物理内存有 2^22 个页框，一位标记一个页框需 2^22 位，即 2^19 字节＝512 KiB。

页面置换：FIFO 换最早入内存页，可能有 Belady 异常；LRU 换最近最久未使用页；OPT 换未来最晚使用页，只作理论比较。缺页题按访问序列逐步列表，不凭直觉数。

文件分配：连续分配便于顺序与随机访问但扩展和碎片有问题；链式分配便于增长但随机访问弱；索引分配通过索引块定位。绝对路径从根出发，相对路径从当前目录出发。

## 4 网络分层与协议

| OSI 层次 | 核心职责或例子 |
|---|---|
| 物理层 | 比特传输、接口电气／机械／功能／过程特性 |
| 数据链路层 | 帧、MAC、差错检测；交换机主要工作层次 |
| 网络层 | IP 寻址与路由；路由器 |
| 传输层 | TCP／UDP，端到端进程通信 |
| 会话层 | 会话组织与管理 |
| 表示层 | 数据表示、转换等 |
| 应用层 | HTTP、DNS、SMTP 等应用协议 |

TCP 提供有序可靠字节流，不保留应用消息边界；UDP 提供数据报，不由协议本身保证可靠有序。应用也可在 UDP 上实现可靠机制，不能说所有 UDP 应用都不可靠。

DNS 将名称映射到记录；DHCP 分配网络配置；ARP 在 IPv4 局域链路内解析下一跳 IP 到链路地址，不是跨互联网查任意设备 MAC。

子网前缀 /p 表示网络部分 p 位。普通 IPv4 子网主机位 h=32−p，通常可用主机数为 2^h−2；/31 点到点和 /32 等属于例外。/29 有 8 个地址，普通子网可用 6 个。

VLAN 划分二层广播域；跨 VLAN 通信通常需三层转发。NAT 改写地址映射，不自动提供完整安全边界。IPv6 过渡常见双栈、隧道、地址转换，目标与代价不同。

## 5 通信与性能公式

| 问题 | 公式或方法 | 前提 |
|---|---|---|
| 无噪声有限带宽信道 | 最高码元速率 2B；M 个信号状态时比特率 2B log₂M | 理想奈奎斯特模型 |
| 有噪声信道容量 | C=B log₂(1+S/N) | S/N 用线性比值，dB 需先转换 |
| Amdahl 加速比 | S=1/[(1−f)+f/s] | f 是原执行时间可优化比例 |
| Little 定律（工程补充） | L=λW | 稳定系统、匹配边界下的长期平均 |
| 带宽时延积 | 带宽×相应时延 | 先统一 bit/s 与秒，RTT 或单程按问题选 |

自编例：80% 时间可加速 4 倍，总加速比＝1/(0.2+0.8/4)=2.5。即使该部分无限快，上限仍是 5 倍。

自编例：稳定系统平均到达 100 次/秒，平均在系统停留 0.2 秒，平均系统内请求数为 20。它不等于可直接配置的线程数。

系统性能评估常用真实程序、核心程序、小型基准、合成基准；教材按其代表真实运行的准确程度递减介绍。不同测试的负载可比性是结论前提。

## 6 多媒体与补充术语

未压缩音频数据率＝采样率×每样本位数×声道数；未压缩图像容量＝像素数×每像素位数；视频还需乘帧率和时长，再换算字节。压缩比定义可能互为倒数，按题设判断。

无损压缩可精确恢复原数据；有损压缩牺牲部分信息。采样定理中采样率需超过信号最高频率的两倍等条件，与量化位数控制的幅值精度不同。

## 自编自测与参考答案

1. 时间片到期进程转阻塞吗？——通常转就绪；等待 I/O 才是典型阻塞原因。
2. 5 个进程各最多要 2 个同类资源，按上述模型保证不死锁需多少？——6 个。
3. 3000 Hz、32 个信号状态、理想无噪声，比特率上限？——2×3000×5=30000 bit/s。
4. /29 普通 IPv4 子网可用主机数？——6。
5. 4 KiB 页的页内偏移几位？——12。
6. 80% 可提升 4 倍，总加速几倍？——2.5。
7. 48 kHz、16 位、双声道音频每秒未压缩容量？——1536000 bit，即 192000 字节，不含额外封装。
8. 样本练习：2025 上综合 1–2、5、9–11、13、15、64；下综合 17–21、29、32、35、43、52、67、73。

完成标准：列清单位与前提，逐步推导资源、内存、网络和性能题，而非只背一个结果。

## 补强：硬件、语言与操作系统辨析

计算机系统由硬件与软件协同组成；系统软件管理基础资源并提供运行支持，应用软件解决用户业务。冯·诺依曼结构的典型特点是存储程序、指令与数据存于存储器；不能由此推出所有现代处理器只有一种缓存组织。

PC 保存待执行指令相关的地址，IR 保存当前指令，状态寄存器记录条件码等状态。CPU 面向通用控制计算，GPU 擅长大规模并行运算，DSP 针对数字信号处理优化，FPGA 可配置硬件逻辑；选型仍需比较时延、功耗、开发成本和适用算子。

教材中的 RISC 通常强调指令规整、寻址较少和便于流水，CISC 指令较丰富；真实实现不能仅由指令集名称推断性能。地址总线表达地址，数据总线传数据，控制总线传控制信号；接口把设备与系统相连，SATA 是存储设备接口的一种，不是内存总线。

机器语言由机器指令构成；汇编以符号表达指令并含伪指令；高级语言用更抽象的结构表达程序。编译把程序转换为目标形式，解释按运行环境执行语义；同一语言可能结合编译和解释，不能用语言名称绝对划分。

就绪态只等待 CPU，阻塞态等待事件；运行时间片耗尽转就绪，发起阻塞 I/O 转阻塞，I/O 完成通常先转就绪。线程通常共享进程地址空间和打开的资源，但各有执行栈与寄存器上下文。系统调用进入内核服务；用户程序不能任意直接执行特权操作。

同类资源自编计算：n 个进程各最多需要 k 个不可抢占资源、取得全部后能执行完并释放，最坏同时各持有 k−1 个。若资源数为 n(k−1)+1，就能保证至少一个进程获得足量资源继续推进。该公式仅适用于上述单资源类型等条件，多资源类型要分析安全序列。

## 补强：系统工程与网络设计

| 方法 | 记忆核心 | 使用条件 |
|---|---|---|
| 霍尔三维结构 | 时间维、逻辑维、知识维 | 强调系统化分析与总体优化 |
| 切克兰德软系统方法 | 认识问题、根底定义、概念模型、比较、选择、实施、反馈 | 适用于目标及人的因素难完全量化的情境 |
| 并行工程 | 产品与相关过程协同设计 | 早期纳入制造、保障等角色减少返工 |
| 综合集成法 | 专家知识、数据和计算相结合，由定性到定量 | 面向开放复杂巨系统 |
| WSR | 物理、事理、人理 | 同时考虑客观条件、做事机制和人员关系 |

系统工程生命周期包括探索研究、概念、开发、生产、使用、保障和退役。MBSE 三支柱按教材为建模语言、建模工具和建模思路；价值在贯通需求、设计、分析与验证，而不是只制作图形。

网络设计先分析业务、用户、平台和网络需求，再确定逻辑拓扑、地址与路由、冗余、安全和物理实施，最后按业务负载验收。二层交换主要按 MAC 地址转发，三层路由按网络层地址选路；STP 处理二层环路，LACP 聚合链路，VRRP 提供虚拟网关冗余。RIP 属于距离向量方法，OSPF 属于链路状态方法，BGP 用于自治系统间路由并强调策略。

IPv4/IPv6 过渡常见双栈、隧道和地址翻译；隧道是封装，不天然提供加密。VPN 需要明确隔离、认证与加密需求；防火墙过滤流量也不能替代应用身份授权。无线接入的竞争、覆盖和干扰影响实际吞吐量，不能用标称带宽直接作为业务容量。

性能验证应给出负载模型、并发、数据规模、预热条件、吞吐量、响应时间分位数与失败率。平均值会掩盖长尾，压测工具吞吐不足也会使结果失真。

自编自测：三个进程各最多需要五个同类资源，按上述条件保证推进需多少？答案：3×4+1=13。路由冗余与链路聚合是否同一机制？答案：否，分别解决网关/路由可用性与链路聚合等问题。

## 补强：外设分类

键盘、鼠标等输入设备把操作转为系统输入；显示器、打印机等输出设备呈现结果；扫描仪与摄像头采集图像；磁盘等外存保存数据。设备分类要看具体功能，多功能设备可能兼有输入输出能力。外设、接口、总线和驱动分别是设备、连接规范、传输通道和软件控制支持，不能混为同一层次。

## 教材案例提要：网络构建

| 教材案例 | 设计主线 | 不能省略的验证 |
|---|---|---|
| 高可用网络 | 分析接入、汇聚、核心各层的单点与冗余路径 | 二层环路、切换时间、故障域和实际业务连通性 |
| 园区双栈 | 评估设备和服务能力，制定地址与升级计划，兼顾现有 IPv4 业务 | IPv4 与 IPv6 的路由、DNS、安全策略和业务访问分别验证 |
| 5G 应用 | 以智能电网等场景连接感知设备、网络与平台分析能力 | 按业务区分带宽、连接规模、时延和可靠性要求 |

教材案例提要不能替代原题拓扑或厂商配置。自测：双栈设备能转发 IPv6 是否说明业务升级成功？答案：不能，还需应用、解析、路由与安全等全链路验证。

## 补强：程序语言的组成

程序语言的基本组成可从三组理解：表达式把变量、常量、字面量与运算符组合为计算；流程控制决定分支、循环、函数调用与异常处理的执行路径；集合组织多个数据，如字符串、数组和哈希映射。表达式回答“算什么”，流程回答“何时、按什么顺序算”，集合回答“数据怎样组织”。这些组成要素与编译阶段的词法、语法、语义分析不是同一个分类维度。
